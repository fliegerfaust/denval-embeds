# denval-embeds

Собранные интерактивные разборы для ДенВал.Класс — то, что вставляется
`<iframe>` на онлайн-доску или в урок.

Публикуется через GitHub Pages: <https://fliegerfaust.github.io/denval-embeds/>

## Что здесь лежит

| Файл | Что это |
| --- | --- |
| `index.html` | Список разборов с готовым кодом для вставки |
| `stereo-8-6.html` | Задача 8.6 — сечение правильной треугольной призмы, 7 шагов |

Каждый разбор — **один самодостаточный файл**: шрифты вшиты, внешних запросов
нет. Поэтому он одинаково работает на доске, в офлайне и там, где чужие домены
закрыты.

## Репозиторий публичный — почему это нормально

Здесь только собранные страницы разборов. Кода платформы, ключей и данных
учеников тут нет и быть не должно: всё это живёт в приватном `denval-class`.
Публичным репозиторий сделан потому, что GitHub Pages на бесплатном тарифе
раздаёт только их.

**Перед тем как что-то сюда добавить — проверь, что файл можно показать
незнакомому человеку.**

## Как обновить разбор

Руками сюда ничего копировать не нужно. Исходники живут в основном репозитории
(`denval-class/experiments/stereo-3d/src/page.html`), оттуда же и публикуется —
одной командой из корня `denval-class`:

```bash
npm run embeds:deploy
```

Она пересобирает разборы, копирует их сюда, коммитит, пушит и ждёт, пока Pages
реально начнёт отдавать новые байты (сверяет SHA-256). Занимает около минуты.

Адреса не меняются, поэтому вставленные на доску iframe обновляются сами.
